# Requirements: PFT WhiteLabel v1.4 — Klaviyo Purchase-Coverage Fix

**Defined:** 2026-07-03
**Core Value:** Trading Cult can see every real purchase outcome (not just completed) in Klaviyo, so failed/expired attempts feed marketing segments same as completions do.

## v1 Requirements

### Purchase Failure Tracking

- [x] **KLAV-01**: Every real customer-facing failed/expired/cancelled payment fires the existing `purchase_failed` tracking event so it reaches Klaviyo, matching the coverage `purchase_completed` already has (cron expiry job, Stripe, FanBasis, PayPal, NOWPayments/crypto call sites) — SHIPPED (7 genuine sites wired; Paysafe covered via generic callback routing)
- [x] **KLAV-02**: The `purchase_failed` event carries a reason/error-code property visible in Klaviyo (adapter's `buildProperties()` must promote `errorCode`/`reason`, not drop it) — SHIPPED (`reason` + `error_code` snake_case properties, table-driven)
- [x] **KLAV-03**: The `purchase_failed` event uses a stable, retry-safe eventId per payment (mirrors `purchase:<paymentId>` pattern) so a resent gateway webhook doesn't double-fire the event — SHIPPED (`purchase_failed:<paymentId>`, dispatcher isDuplicate honors explicit eventId)
- [x] **KLAV-04**: Internal dedup/race-guard status flips (e.g. the two non-customer-facing `expired` writes in `payment.service.modular.ts` that clean up duplicate/superseded PAP payment docs) never fire `purchase_failed` — SHIPPED (silent by construction: emits only at explicit call sites, zero calls in payment.service.modular.ts)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Separate `purchase_expired` event (distinct from `purchase_failed`) | Normalizing expired/cancelled/failed into one existing `purchase_failed` event + a `reason` property avoids Klaviyo event-taxonomy bloat and matches how gateways already normalize their own statuses into one Payment.status enum |
| New tracking event catalog / dispatcher / adapter architecture | `purchase_failed` was already fully built (catalog, toggles, Klaviyo mapping, typed helper) — this milestone only wired existing call sites, no framework change needed |
