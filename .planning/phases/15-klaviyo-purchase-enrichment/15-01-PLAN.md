Create a new file `pft-backend/src/app/modules/Payment/utils/resolveProgramContext.ts` exporting an async function that Wave-2 emit utils use to turn a payment's `programId` (or `currentProgramId` for PAP) into the program-context fields that live on the Program model, not on Payment.

Signature:
```ts
import { Program } from "../../Admin/Program/program.model";

export interface ResolvedProgramContext {
  programName?: string;   // Program.name (or displayName fallback) — the challenge name
  platform?: string;      // Program.platform ("MT4" | "MT5") — normalized
  challengeType?: string; // Program.challengeType — normalized closed-vocab
  phase?: string;         // Program.programStage ("phase1"|"phase2"|"phase3"|"funded")
  accountSize?: string;   // Program.accountSize
}

/**
 * Lean single-field-selected Program lookup that never throws and returns {}
 * on any miss/error, so tracking emit utils can call it fire-and-forget without
 * a tracking failure ever surfacing to the payment flow.
 */
export async function resolveProgramContext(
  programId: string | null | undefined,
): Promise<ResolvedProgramContext> { ... }
```
Implementation notes:
  - Guard: if `!programId` return `{}` immediately.
  - `const prog = await Program.findById(String(programId)).select("name displayName platform challengeType programStage accountSize").lean();`
  - Wrap the query in try/catch; on any error return `{}` (never throw — matches the emit utils' fire-and-forget safety contract).
  - Map: `programName: prog?.name || prog?.displayName || undefined`, `platform: prog?.platform ?? undefined`, `challengeType: prog?.challengeType ?? undefined`, `phase: prog?.programStage ?? undefined`, `accountSize: prog?.accountSize != null ? String(prog.accountSize) : undefined`.
  - Return only defined values (undefined for anything missing — never a placeholder/guess, per SC5's "normalized ID/string values only" and the omit-when-unknown convention from Phase 14).
Use `// eslint-disable` only if the codebase requires it for `.lean()` typing; prefer casting the lean result to a minimal local type (`{ name?: string; displayName?: string; platform?: string; challengeType?: string; programStage?: string; accountSize?: string }`) rather than `any` where clean.
